# Financial-Calculator | Gestão e Planeamento Financeiro

A Financial-Calculator é uma ferramenta interativa desenvolvida para auxiliar utilizadores no cálculo de métricas financeiras essenciais. O projeto foca na precisão matemática e numa interface simplificada, ideal para quem procura organizar as suas finanças pessoais ou simular investimentos.

**Link de Acesso:** [Visualizar Calculadora](https://samuel123d.github.io/Financial-Calculator)

---

## Resumo do Projeto

Este utilitário permite realizar operações financeiras complexas de forma rápida. Seja para calcular juros, planear poupanças ou converter valores, a calculadora fornece resultados imediatos através de uma estrutura lógica robusta e uma interface amigável para qualquer tipo de dispositivo.

### Tecnologias e Ferramentas

| Categoria | Tecnologias Utilizadas |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, JavaScript |
| **Lógica** | Algoritmos Matemáticos Financeiros |
| **UX/UI** | Design Focado em Usabilidade |
| **Hosting** | GitHub Pages |

---

## Estrutura de Diretórios

O projeto mantém uma organização limpa, focada na rapidez de processamento dos scripts:

* **assets/**: Ficheiros de estilização e ícones intuitivos para o utilizador.
* **src/**: Scripts JavaScript responsáveis pelos cálculos e validação de dados.
* **index.html**: Interface principal da calculadora e área de resultados.

---

## Funcionalidades Principais

O projeto demonstra rigor técnico no tratamento de dados numéricos:

> **Precisão em Cálculos Dinâmicos**
> Implementação de funções que processam variáveis financeiras em tempo real, garantindo que o utilizador tenha uma visão clara do seu cenário financeiro antes de tomar decisões.
